개인정보처리방침

시행일: 2026-11-19 (이전 판: 2026-11-18)

ai-company-uploader(이하 "이 도구")는 채널 운영자 한 사람이 자기 컴퓨터에서만 쓰는 개인용 도구입니다. 운영자가 직접 운영하는 채널 하루 한 구절과 근데 진짜는?(한국어·영어·일본어·스페인어 채널)에, 운영자가 하나하나 확인하고 승인한 영상·글·댓글을 올립니다. 누구나 가입해 쓰는 서비스가 아니며, 다른 사람의 계정에는 접근하지 않습니다.

1. YouTube API 서비스 사용

이 도구는 YouTube API 서비스를 사용합니다. 이 도구를 쓰는 것은 YouTube 서비스 약관에 동의하는 것이며, Google이 처리하는 정보에는 Google 개인정보처리방침이 적용됩니다.

2. 받는 정보

  • 운영자가 Google(YouTube)·Meta(Threads, Instagram) 로그인 화면에서 허용하면, 운영자 본인 계정의 접근 토큰과 채널 이름·아이디·주소를 받습니다.
  • 운영자 본인 채널에 올린 영상의 공개 상태, 조회수·좋아요·댓글 수, 평균 시청 시간 같은 성과 숫자와, 그 영상에 달린 댓글(작성자 이름, 내용)을 읽습니다.
  • 크리에이티브 커먼즈(CC BY) 영상을 찾을 때는 YouTube에 공개된 영상 정보(제목, 채널 이름, 조회수, 라이선스)를 검색합니다.
  • 그 밖의 개인정보는 받지 않으며, 쿠키나 추적 도구를 쓰지 않습니다.

3. 쓰는 곳

운영자가 승인한 콘텐츠를 운영자 본인 채널에 올리고 공개 시각을 예약하는 일, 운영자 채널의 성과를 확인하는 일, 운영자 채널에 달린 댓글에 운영자가 승인한 답글을 다는 일에만 씁니다. 광고, 판매, 다른 서비스로의 전달에는 쓰지 않습니다.

4. 보관과 보호

토큰과 위 정보는 운영자의 컴퓨터 안 파일에만 저장되며, 외부 서버로 보내거나 다른 사람과 공유하지 않습니다. 이 도구의 Google API 사용과 다른 앱으로의 정보 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 권한 해제와 삭제

  • 운영자는 언제든 Google 보안 설정의 '서드 파티 앱 및 서비스'에서 이 도구의 접근 권한을 해제할 수 있습니다. 해제하면 이 도구는 더 이상 계정에 접근할 수 없습니다.
  • 저장된 토큰은 운영자 컴퓨터의 설정 화면에서 바로 지울 수 있습니다.
  • YouTube에서 받은 정보(성과 숫자, 댓글)는 운영자 확인용으로만 보관하며, 30일마다 새로 받아 갱신하고 필요 없어진 정보는 지웁니다. 권한을 해제하거나 삭제를 요청하면 7일 안에 모두 지웁니다.

1. Use of YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Information processed by Google is subject to the Google Privacy Policy.

2. Information accessed

  • When the owner grants access on the Google (YouTube) or Meta (Threads, Instagram) sign-in screen, the tool receives access tokens for the owner's own account and the channel name, ID and URL.
  • It reads the status and statistics (views, likes, comment counts, average view duration) of videos on the owner's own channels, and comments (author name and text) left on those videos.
  • To find Creative Commons (CC BY) videos it searches public YouTube video information (title, channel name, view count, license).
  • No other personal information is collected. No cookies or tracking technologies are used.

3. How it is used

Only to upload and schedule the owner's approved content on the owner's own channels, to show the owner how those videos perform, and to post replies the owner has approved to comments on the owner's own videos. It is never used for advertising, sold, or shared with other services.

4. Storage and protection

Tokens and the information above are stored only in files on the owner's computer and are never sent to an external server or shared with anyone. The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Revoking access and deletion

  • Access can be revoked at any time on the Google security settings page (Third-party apps & services). After revocation the tool can no longer access the account.
  • Stored tokens can be deleted immediately from the tool's settings screen on the owner's computer.
  • Data obtained from YouTube (statistics, comments) is kept only for the owner's review, refreshed at least every 30 days, and data that is no longer needed is deleted. If access is revoked or deletion is requested, all of it is deleted within 7 days.
