개인정보처리방침

시행일: 2026-11-18

ai-company-uploader(이하 "이 도구")는 하루 한 구절 채널 운영자가 본인 계정에 콘텐츠를 올리기 위해 직접 만든 개인용 도구입니다.

1. 받는 정보

운영자가 Google(YouTube)·Meta(Threads, Instagram) 로그인 화면에서 허용하면, 운영자 본인 계정의 접근 토큰과 채널 이름·아이디만 받습니다. 다른 사용자의 정보는 받지 않습니다.

2. 쓰는 곳

운영자가 승인한 영상·글·댓글을 운영자 본인 채널에 올리고, 올린 결과(링크, 공개 상태, 조회수 같은 성과)를 확인하는 데에만 씁니다.

3. 보관과 보호

토큰은 운영자의 컴퓨터 안 파일에만 저장되며 외부 서버로 보내거나 다른 사람과 공유하지 않습니다. 광고, 판매, 분석 목적으로 쓰지 않습니다.

4. Google 사용자 데이터

이 도구의 Google API 사용과 다른 앱으로의 정보 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 삭제

운영자는 언제든 Google 계정의 "연결된 앱", Meta의 "앱 및 웹사이트" 설정에서 접근 권한을 해제할 수 있으며, 해제하면 이 도구는 더 이상 계정에 접근할 수 없습니다. 저장된 토큰은 운영자 컴퓨터에서 바로 지울 수 있습니다.
